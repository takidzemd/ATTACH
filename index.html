Руководство по разделам

  • Каталог аксессуаров — чтобы быстро посмотреть, какие аксессуары к каким категориям можно предложить.

  • Калькулятор — для расчета АТТАЧа и понимания, сколько доп продаж нужно для достижения цели.
  • Морской бой — в игровом формате проверить знания по аксессуарам.
  • Чек-лист сотрудника — для руководителя, чтобы оценить знания и навыки сотрудника, и понимания сотрудником критериев оценки.
